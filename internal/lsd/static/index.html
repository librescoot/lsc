Cloud

Sunshine, run by rescoot.org, gives you remote lock and unlock, location, telemetry and the companion app. radio-gaga connects the scooter to it. uplink-service connects to a backend of your own.

This scooter

Connectivity services

Connect to Sunshine

Create a bootstrap token in your Sunshine settings and paste it here. The scooter registers with its IMEI and board serials, Sunshine adds it to your account, and radio-gaga is configured and started.

Updates

    
Each board runs its own update-service. Channels are stable, testing and nightly; a channel switch downloads a full image, later updates on the same channel come as deltas.

    


    

      
Install a file

      
A .mender image or a .delta patch. MDB files install from where they land. DBC files are staged on the MDB and copied to the dashboard when you install; the dashboard is powered on for that if needed.
